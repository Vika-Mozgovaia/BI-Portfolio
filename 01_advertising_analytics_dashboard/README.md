# Advertising Analytics Dashboard

## Project Overview

Interactive BI dashboard for analyzing the performance of mobile application advertising campaigns.

The dashboard enables marketing teams to monitor campaign efficiency, evaluate ROI, compare acquisition channels, analyze campaign types and device segments, and identify optimization opportunities.

---

## Dashboard Overview

![Dashboard Overview](images/dashboard_overview.png)

---

## Key Features

- KPI overview (Revenue, Cost, ROI, Orders, Conversion)
- Campaign type analysis
- Advertising channel analysis
- Device type analysis
- Interactive filters
- Period-over-period (PoP) comparison
